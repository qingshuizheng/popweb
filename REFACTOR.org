* popweb 重构计划（分支 =refactor/full=）

基线：上游 =manateelazycat/popweb= @ =86d72c6=（2024-10-05）。
Elisp 与 Python 两侧同属本仓库，一起改；对外保持 **1:1 功能**：Emacs 公开命令与
选项同名、EPC 方法名与参数形状不变、扩展插件协议（=popweb= 实例的三个方法）
不变。**org-roam 扩展整体丢弃**（连同 README 的安装/截图/配置段）。

** 目标

1. **一比一还原**：翻译、LaTeX、取色器、URL 预览、Anki 复习四类弹窗的行为、
   默认值、快捷键、生成的 HTML/JS 与上游一致；只修正下面「校正」列出的缺陷，
   每条都有测试钉住。
2. **docstring 完整**：Elisp 的 =defun=/=defmacro=/=defsubst=/=defvar=/=defconst=/
   =defcustom=/=cl-defstruct=，Python 的 module/class/function 都有 docstring；
   首行是完整句子，参数在正文里被提到，Elisp 不超过 80 列。
3. **可验证**：ERT + Python =unittest= 测试，加机器判据（docstring/编译/协议/
   覆盖），一条命令跑完。
4. **去掉 org-roam**：=extension/org-roam/= 删除，README、加载路径、测试里不再出现。

=popweb-enable-debug= 时 macOS 也炸。重构改为 =push= / =cl-pushnew=，语义不变。

*** 扩展插件协议（保持不变）

扩展 Python 模块由 Emacs 通过 =call_module_method= 加载，函数第一个参数是
=POPWEB= 实例，其后是 Emacs 传来的参数。扩展只可调用：

- =popweb.get_web_window(module_name)= → =WebWindow=
- =popweb.adjust_render_pos(...)= → =(x, y)=
- =popweb.build_web_channel(...)= → 无返回

** 校正（与上游的差异，全部记录在 =CORRECTIONS.org=）

1. =extension/color-picker/color-picker.el= → =popweb-color-picker.el=：上游
   =provide= 是 =popweb-color-picker=，README 也让人 =(require 'popweb-color-picker)=，
   按文件名加载必然失败。
2. =popweb--build-process-environment= 用 =push= / =cl-pushnew= 代替 lexical 变量上的
   =add-to-list=（上游在 Linux/debug 下抛 =void-variable=）。
3. =WebWindow.eval_in_emacs= 显式接收参数列表，与模块级 =eval_in_emacs= 的签名一致
   （上游靠 =*args= 恰好一个参数才成立）。
4. =POPWEB.build_web_channel= 用 =setattr= 把 =pyqtSlot= 装饰到**真正的槽方法**上
   （上游把装饰结果存成名为 =slot_method_name= 的新属性，QWebChannel 看不到
   =expanded_on_bridge_cmd=）。
5. =CookiesManager= 删掉 =domain_matching= 中 return 之后不可达的分支：上游实际
   行为是「加载磁盘上所有域名」，重构保留该有效行为并写清楚。
6. =popweb-anki-review.el= 删掉重复定义的 =popweb-anki-review--sentence=；
   =popweb-anki-review.py= 的 =\[sound:...= 正则改为 raw string（消除 SyntaxWarning）。
7. =popweb-latex.el= 不再 require =dash=；唯一的 =--> =线程宏展开为等价 =
   =replace-regexp-in-string= 调用，依赖从 1 个降为 0。
8. 删除死代码：=destroy_view_list=、=proxy_string= 全局（只写不读）。
9. docstring 修正：=popweb--first-start= 提到不存在的
   =WEBENGINE-INCLUDE-PRIVATE-CODEC=；=popweb-color-picker.el= 头部描述抄自
   KaTeX 插件。
